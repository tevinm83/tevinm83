## Current work

**Spacecraft attitude & inertia estimation** - Advanced Space Concepts Laboratory, RPI
Vision-based attitude and inertia estimation for a tumbling, non-cooperative spacecraft.
- Multiplicative Extended Kalman Filter (MEKF) estimating attitude, angular velocity, and principal inertia ratios from camera-derived angular-velocity measurements
- 1,000-frame BlenderProc RGB-D dataset of a tumbling spacecraft passing through eclipse
- 9° RMS attitude error and 2.6% inertia-ratio error through eclipse
- Abstract accepted to the AAS/AIAA Space Flight Mechanics Meeting (January 2027)
